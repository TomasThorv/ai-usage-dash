Owner: Tomas. Executor: OpenCode. Goal: dashboard reads as crafted by a human designer, not generated by an LLM.

## AI-slop diagnosis — current dashboard

Visual tells that scream "Claude built this":

1. **Glassmorphism stack** — `backdrop-blur-[20px]` + `bg-surface-glass` + inset white border + heavy drop shadow. Three layers of background (`GradientBackdrop`, `GridOverlay`, `Vignette`) compounding on every page. Peak 2021 dribbble.
2. **Cyan→violet gradient logo and accents** (`#5eead4` → `#a78bfa`). Literally the default ChatGPT/Claude/v0 palette. Same gradient on the logo box, same colors on token bars, same colors on glow shadows.
3. **Glow shadows on hover** (`0 0 36px rgba(94,234,212,0.18)`). Two glow colors layered. Cyan + violet again.
4. **Decorative grid overlay** — `--color-grid-line: rgba(99,179,237,0.08)`. Faint cyan grid behind everything. No information value, pure aesthetic.
5. **Vignette** — fullscreen darkening overlay. Adds nothing, present because v0/Claude templates always add one.
6. **Animated count-ups everywhere** — every metric tweens. CountUp on tokens, spend, providers, requests. Reads as "look how alive my dashboard is" — distracts from the numbers.
7. **Framer-motion on the card hover** — `y: -4` lift + glow. Same hover affordance as every shadcn-block-marketplace card.
8. **Two-tone token bar** (cyan in / violet out). Same palette again, no semantic reason input/output should be those colors.
9. **Inter Variable + JetBrains Mono** — the default AI-generated app stack. Fine fonts, but they tag the app as generated.
10. **Card geometry** — `rounded-2xl` (22px), `min-h-[220px]`, `p-5`, three-section flex inside. Identical to ~every Next.js dashboard template.
11. **Empty/dashed quota placeholder** (`border-dashed text-text-faint "no quota"`). Generic shadcn empty-state.
12. **`max-w-[1600px]` centered shell** + fixed translucent header with logo+metrics+actions row. Standard AI layout block.
13. **Status colors as named tokens** (`status-ok / warn / error / stale`) using emerald/amber/red/orange — exact tailwind defaults, no project voice.

Net: every individual choice is fine; their *combination* is the AI fingerprint.

## Design direction — pick a voice

Recommend: **utilitarian terminal-adjacent**. The product is a self-hosted ops dashboard for a developer audience. Lean into that instead of fighting it.

- Reference points: Linear settings panes, Vercel Observability v2, Supabase project home, Datadog new dashboard, Ghostty's chrome. *Not* dribbble glassmorphism, *not* Framer marketing pages.
- Information density up, decoration down. Numbers should be the loudest thing on screen, not the chrome.

If user prefers a softer/branded direction instead, swap the palette and type but keep the structural changes below.

## Concrete changes

Each item lists files to touch + the change. OpenCode should treat the items as ordered; commit after each numbered group.

### Group 1 — Strip background decoration

- `app/page.tsx:64-67` — delete `<GradientBackdrop />`, `<GridOverlay />`, `<Vignette />`.
- `components/Background/` — delete the three files. Remove the directory.
- `app/globals.css:32-35` — replace `background: var(--color-bg-deeper)` with a single flat token (see Group 2). No gradient, no grid overlay, no vignette.

Reason: three stacked decorative layers is the strongest AI-slop tell on the page. Flat surface = looks intentional.

### Group 2 — Repalette

Swap `app/globals.css` `@theme` block:

```css
@theme {
  /* surfaces */
  --color-bg: #0b0b0c;            /* near-black, not navy */
  --color-bg-elevated: #141416;
  --color-surface: #18181b;       /* card */
  --color-surface-hover: #1f1f23;
  --color-border: #27272a;
  --color-border-strong: #3f3f46;

  /* text */
  --color-fg: #fafafa;
  --color-fg-muted: #a1a1aa;
  --color-fg-faint: #71717a;

  /* one accent, not two */
  --color-accent: #f5f5f5;        /* neutral; brand = type+layout, not color */

  /* status (mute the saturation) */
  --color-ok:    #4ade80;
  --color-warn:  #f59e0b;
  --color-error: #f87171;
  --color-stale: #a1a1aa;

  --radius-card: 8px;             /* was 22px — sharper */
  --radius-control: 4px;

  --font-sans: 'Geist', ui-sans-serif, system-ui, sans-serif;
  --font-mono: 'Geist Mono', ui-monospace, 'SF Mono', monospace;
}
```

- Drop **all** glow tokens (`--shadow-glow-cyan`, `--shadow-glow-violet`).
- Drop the cyan/violet accent tokens. Token bar uses `fg-muted` for input, `fg` for output (or a single brand hue if user picks one — confirm).
- `app/layout.tsx:7-17` — swap Inter for Geist (`geist/font/sans`, `geist/font/mono`). Already a Vercel app; package is `geist`. If user objects, fall back to `IBM Plex Sans`/`Plex Mono` — anything but Inter.

### Group 3 — Kill glassmorphism

- `components/Card/GlassCard.tsx`
  - Rename file + component to `Card` / `Card.tsx`. The "Glass" name is the giveaway.
  - Drop `backdrop-blur-[20px]`, `bg-surface-glass`, the `inset_0_1px_0_rgba(255,255,255,0.06)` highlight, and the `glow` prop entirely.
  - New base: `relative w-full rounded-[8px] bg-surface border border-border`.
  - Hover (when `interactive`): `border-color: var(--color-border-strong)`. No lift, no glow, no framer-motion. Plain CSS transition on `border-color`, 120ms.
- `components/TopBar/TopBar.tsx:35` — drop `backdrop-blur-[24px]` and `bg-bg-deeper/60`. Use solid `bg-bg border-b border-border`.
- Search the codebase for any other `backdrop-blur` / `bg-*-glass` and remove.

### Group 4 — Logo and brand mark

- `components/TopBar/TopBar.tsx:41-48` — remove the `bg-gradient-to-br from-accent-cyan to-accent-violet` square. Replace with either:
  - a small monochrome SVG mark (one shape, one color), or
  - just the wordmark "AI Usage" in `font-mono` `tracking-tight`, no icon.
- The gradient square is the single most "v0 generated" element on the page.

### Group 5 — Detune the motion

- `components/CountUp/CountUp.tsx` — keep it for `tokens` and `spend` aggregates only. Replace per-card token/request CountUps with plain text. Reason: ten things tweening simultaneously reads as decorative.
- `components/Card/ProviderCard.tsx:85-96` — replace the dual cyan/violet bar with a single muted bar showing total tokens vs. quota. Show `in / out` as a small mono-font breakdown line below, no bar. Two-tone bars without a legend are noise.
- `components/Grid/DashboardGrid.tsx` — keep reorder, but drop `LayoutGroup` animations on initial mount. Reorder-on-drag only, no entry animation.

### Group 6 — Typography and density

- Headings: tighten. `tracking-tight` on display numbers, `font-mono tabular-nums` on every count. The "data is mono" rule is the cheapest signal that a designer touched this.
- `components/TopBar/TopBar.tsx` aggregates: render the value in mono, the label in sans uppercase 10px tracked. Vercel-Observability look.
- `ProviderCard` header: provider name in sans-medium, status dot + "fresh / stale / 12s ago" in mono `text-[11px] text-fg-muted`. Drop `text-text-faint` everywhere — collapse to two text-muted levels (`fg-muted`, `fg-faint`).
- Card padding: bump from `p-5` to `p-6` and tighten the inner stack from `space-y-3` to `space-y-2`. Counterintuitive, but more outer breathing room + tighter inner rhythm = "designed".

### Group 7 — Quota ring redesign

- `components/QuotaRing/QuotaRing.tsx` — current ring is fine geometry, but the "no quota" dashed circle empty-state is generic shadcn. Replace with a left-aligned label `"no quota tracked"` in `text-fg-faint text-[11px]` and remove the dashed circle.
- Ring colors: single `--color-fg` stroke at 70% opacity for used, `--color-border` for track. Drop multi-color rings if any.

### Group 8 — Empty / loading / error states

- `components/Grid/EmptyState.tsx` — audit. If it has illustrations, large CTAs, or gradient buttons, strip to a single sentence + one ghost-styled `Add provider` link. Linear-style empty.
- `components/Card/CardSkeleton.tsx` — confirm it uses a single `bg-surface-hover animate-pulse` block, not gradient shimmer.
- `components/Card/CardError.tsx` — error icon should be `lucide` `AlertCircle` in `text-error`, no filled background. One-line error message in `font-mono text-[12px]`.

### Group 9 — Final passes

1. Run `web-design-guidelines` on every changed file under `components/`. Fix every flagged item.
2. Run `deslop` on the branch diff. Strip any defensive `try/catch`, redundant comments, `as any` casts introduced.
3. `pnpm lint && pnpm typecheck && pnpm test` must pass.
4. `pnpm test:visual` will fail — re-baseline screenshots intentionally and commit the new baselines as part of the final commit.
5. `pnpm dev`, manually walk: setup wizard → dashboard with 0/1/many providers → expand a card → settings drawer → reorder cards. No regressions.

## Out of scope

- Not changing data flow, SSE, providers, encryption, or routes.
- Not adding new providers or features.
- Not adding light mode (separate ticket).
- Not replacing framer-motion as a dep (still used for reorder).

## Acceptance

Done when:
- No `backdrop-blur`, no glow shadows, no gradient backgrounds in `app/` or `components/`.
- Palette has zero cyan-violet pairs.
- Typography uses mono for numbers, sans for labels, consistent two-level muted scale.
- `web-design-guidelines` review yields zero unresolved findings.
- All tests pass; visual baselines re-captured and committed.
- Dashboard at `/` no longer pattern-matches as "AI dashboard template" on a 5-second glance test.
